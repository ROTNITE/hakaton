# Бесплатные 3D-модели для MetaRescue: референсы 09–20

Проверка источников: **10 ноября 2026 года**. Основание: `3d-asset-catalog-v1/specs.json`, изображения 09–20, `../3d-visual-direction.md`, `../current-concept.md` и `../../unreal/README.md`. Цель — современный гражданский квартал после разрушения, реалистичные материалы, оранжевая спасательная техника, бирюзовая инфраструктура, читаемые проезды. Текущий проект — Unreal Engine 5.8.

Ниже реальные скачиваемые модели и наборы. Сходство и объём доработки — моя оценка по нашим референсам и превью авторов. Это подборка для последующего импорта: геометрия, коллизии, масштаб и работа моделей в нашей сцене ещё не проверены. №12–15 особенно требуют адаптации; №14 не является готовой заменой нашей платформы.

## Лицензии и скачивание

- **CC0:** можно изменять, включать в проект и распространять вместе с ним; указание автора необязательно. Так лицензированы выбранные модели Poly Haven. [Условия Poly Haven](https://polyhaven.com/license).
- **CC BY 4.0:** можно изменять и использовать, в том числе коммерчески; нужно сохранить автора, ссылку на модель и лицензию, отметить изменения. Это не лицензия NC или ND. [Условия Creative Commons](https://creativecommons.org/licenses/by/4.0/).
- **Sketchfab:** для выбранных моделей публичный API сообщает `isDownloadable=true`, лицензию и наличие архивов GLB/glTF. Требуется аккаунт; фактическая выдача архива после входа не проверена. Постоянных публичных ссылок на архивы нет: сервис выдаёт временные ссылки после авторизации. [Официальное описание скачивания](https://sketchfab.com/developers/download-api/downloading-models).
- **Poly Haven:** на странице выбрать разрешение **2K** и формат **Blend**, **FBX** или **glTF**, затем Download. Важен комплект с текстурами: один файл FBX или Blend по прямой ссылке не включает все зависимости. Для десяти выбранных моделей проверены открытые FBX-файлы через HTTP HEAD — ответы 200, размеры совпали с манифестами API.
- Формат `.blend` у моделей Sketchfab не предполагается автоматически. Ниже GLB/glTF подтверждены метаданными архивов; исходный формат указан отдельно только там, где его перечисляет автор.

Метаданные проверки, авторы, лицензии, размеры архивов и ссылки на API сохранены в [open-model-sources-2026-11-10.json](open-model-sources-2026-11-10.json). Число треугольников — сведения площадки, не результат нашего измерения. MB ниже — десятичные; размеры полных наборов не равны размеру одной выбранной детали.

## Как я бы собирал первую партию

1. **Сначала:** 09, 11, 16, 17, 18, 19, 20, генератор и электрошкаф. Они быстро дают улицу и работающий пункт помощи без сложной новой механики; всё равно нужны масштаб, материалы и коллизии.

## Подготовка для Unreal

- **Форматы:** Unreal поддерживает FBX и glTF/GLB; Blend использовать для редактирования и экспорта. Для наших отдельных статических объектов — Static Mesh. [glTF в Unreal](https://dev.epicgames.com/documentation/unreal-engine/gltf-file-format-support-in-unreal-engine), [FBX Static Mesh Pipeline](https://dev.epicgames.com/documentation/unreal-engine/fbx-static-mesh-pipeline-in-unreal-engine?lang=en-US).
- **Масштаб:** сверить в Blender размеры из нашего каталога и результат в сантиметрах UE: 1 м → 100 см. Не исправлять несоответствие проёма только изменением общего масштаба здания.
- **Материалы:** начать с 1K–2K для мелкого реквизита, более высокое разрешение выбирать по близким кадрам. Проверить Base Color, Roughness, Metallic, Normal. Для карты ARM каналы назначаются отдельно: R — AO, G — Roughness, B — Metallic. При ручной настройке учитывать направление normal map; у выбранной балки автор указывает OpenGL. Автоматический импорт материалов нужно осмотреть в движке.
- **Коллизии:** единый статический завал — простая форма; подвижная балка/барьер — упрощённые выпуклые тела. Медпункт — отдельные формы стен, пола и рампы, сохраняющие проход. UCX-прокси для FBX поддержаны официальным pipeline; не считать коллизию проверенной по наличию красивого превью.
- **Подвижные части:** отделимость крышки кейса, дверей и колёс фургона, головки сенсора не подтверждена метаданными. Проверить до анимации. Эти модели не содержат готовую нашу механику зарядки, связи, обнаружения или спасения.
- **Повторяемость:** для ограждений, фонарей, барьеров и мусора подготовить разумный LOD/упрощение; стоимость в сцене измерять после импорта. Наличие Nanite или PBR не гарантирует нужную производительность.
- **Файлы:** сохранить оригинальные скачанные архивы и лицензию, рабочие правки делать в копиях. В текущую генерируемую сцену добавлять через предусмотренный процесс подготовки либо отдельными актёрами; учитывать предупреждение о регенерации в `../../unreal/README.md`.
