# MetaEvolution Rescue — бенчмарки и физическая 3D-площадка

Снимок 2026-11-09. Единые инструкции и краткий контекст — `AGENTS.md`; подробная концепция — `docs/current-concept.md`.

## 2D-бенчмарк v0.3

Из папки этого пакета:

```powershell
python -B -X utf8 "benchmarks/metarescue-v0.3/main.py"
```

Откроется локальный сайт: пять связок общей миссии, разведка, эвакуация, вероятностные события. Требуется Python 3.10+, внешних Python-пакетов нет. Оригинальный пользовательский релиз сохранён без правок; его 30 тестов проходят, два дополнительных граничных дефекта открыты и описаны в `docs/benchmark-v0.3-review.md`.

## Unreal 3D

Нужны Unreal Engine 5.8 (проверен 5.8.4), Visual Studio C++/Windows SDK и Python.

```powershell
python -B -X utf8 unreal/launch.py --editor
```

Либо открыть `unreal/MetaRescue/MetaRescue.uproject`, карту `Content/Maps/RescueDistrict`, нажать Play. Подробное управление и ограничения — `unreal/README.md`. Для другого каталога движка добавить `--engine "D:\Epic\UE_5.8"`.

В пакет включён собранный Windows Editor-модуль для UE 5.8.4. При несовпадении версии движка/BuildId пересобрать:

```powershell
python -B -X utf8 unreal/launch.py --build --editor
```

Проверка реальной физики без видимого окна:

```powershell
python -B -X utf8 unreal/launch.py --smoke
```

По умолчанию 90 модельных секунд: силы, гравитация, коллизии, обрушение, сенсор и доставка. Стенд использует статический снимок v0.3 и демодиспетчер; нормативный контроллер и пять алгоритмических связок ещё не подключены к физическому исполнению. Пожары/затопления из 2D пока не переносятся в runtime Unreal.

## Внутри

- `benchmarks/metarescue-v0.3/` — текущий пользовательский релиз, неизменённый.
- `benchmarks/metarescue-v0.2/` — исторический ориентир, неизменённый.
- `unreal/` — C++-исходники, сохранённая карта/материалы, генераторы и лаунчер.
- `docs/` — концепция, спецификации, обзоры, план исследований и первоисточники.
- `artifacts/unreal/`, `artifacts/metarescue-v03/` — реальные рендеры/телеметрия и измерения.
- `contracts/`, `tests/`, `environment/`, `controller/`, `web/` — ранее принятые эталоны, проверки и каркас; стенды не объявлены нормативно совместимыми.
- `benchmark/` — самостоятельный ранний черновик, не текущая база.
- `концепция/`, `ТЗ/` — исходная концепция и предоставленные документы постановки.
- `tools/audit_metarescue_v03.py` — воспроизведение двух известных дефектов (ожидаемый exit 1).

Движок, SDK, PDB, временные сборки, готовые venv и лекции в этот пакет не входят. Ассеты геометрии/материалов созданы кодом и API редактора, базовые формы ссылаются на установленный Unreal. Визуальный imagegen-концепт сохранён с prompt отдельно от реальных скриншотов. Старый удалённый пользователем Evolution World не восстановлен. Ссылки старых документов на исходный каталог нормализованы в относительные только в архивной копии.
