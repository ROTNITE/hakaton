Кандидаты Sketchfab требуют авторизованного скачивания; они не импортированы.
Загрузка кандидата Innerscene прервалась по сетевому таймауту; неполный GLB
не является проверенной моделью и не используется.

Производные создаются скриптами, вручную uasset не редактируются:

1. `unreal/tools/bake_disaster_fire.py`: VDB → атласы, метрики покрытия и SHA.
2. `unreal/tools/prepare_disaster_effects.py`: выбранные PNG/JPG → отдельный
   каталог с манифестом источников и SHA каждого файла.
3. `unreal/tools/run_disaster_art.py --inputs <manifest.json> --output <new-dir>`:
   общий lock, единственный Unreal, импорт через `build_disaster_effects.py`,
   проверка неизменности исходников и старых редакций эффектов, SHA uasset.
4. `unreal/tools/prepare_water_catamaran.py`: Blender без auto-exec →
   отдельный FBX/BLEND/PBR2K, манифест SHA и превью. Выбранный размер4,6м
   является игровым проектным решением, не паспортом производителя.
5. Тот же `run_disaster_art.py --kind watercraft`: импорт через
   `build_water_catamaran.py` в `/Game/RescueAssets/WatercraftV1`. Оболочка
   не имеет искусственной сплошной коллизии между корпусами; физика отдельно.

Импорт07 эффектов:15 uasset, без shader errors, старые редакции/исходники
сохранены. В native-scene-04 реальные окна дают33 точки огня. Из фиксированной
