# Критерии повторов MetaEvolution Rescue

Критерии зафиксированы до сравнительных повторов текущего этапа. Измерения
делаются по двум нативным архивам с одним SHA-256 файла мира и ленты
возмущений. Внешние решения идут в исходном порядке. У обоих эпизодов
свои корреляционные ID, поэтому для физического сравнения используются
идентификаторы участников и время модели.

| Измерение | Допуск |
| --- | --- |
| Терминальный статус, число известных и доставленных целей | Совпадение |
| Полученные идентификаторы пострадавших и флаги фактической эвакуации в терминальном срезе | Совпадение |
| Контакты машин в терминальном срезе по агентам | Совпадение |
| Поза припаркованного агента в двух начальных снимках | До 1 мм |
| Отклонение доставленных поз на соответствующем шаге | p95 до 0,20 м, максимум до 1,00 м |
| Момент завершения передачи в пункте помощи | До 0,5 модельной секунды |
| Время окончательной остановки | До 0,5 модельной секунды |

Повтор записанных AI-ответов использует те же семантические запросы и
сохранённую модельную задержку. Для нового запуска контроллер перепривязывает
эпизод и запрос и заново валидирует ответ. В журнале должны быть видны
воспроизведённый ответ, применённая команда и её доставленный результат.
Исторические затраты указываются по исходным попыткам. Сетевой бюджет в
режиме REPLAY должен остаться прежним.

Проверка сохранённого AI-входа подтверждает целостность ответа и задержки.
Физический повтор проверяет команды в новом экземпляре мира. Неполное
совпадение замкнутого прогона отражается с фактическим числом совпавших
ответов, пропусков и причин отказа.
