# Постоянный учёт API

Канонический счётчик — `D:/MetaRescue-output/ai-budget.json`, формат v1.
Учёт встроен в существующий LiveBudget/DeepSeek. Независимого счётчика квоты нет.
Реализация: controller/ai.py, accounting.py, advisor.py, ai_policy.py, main.py.

## Попытки и устойчивость

Перед сетью сохраняются ticket, logical request ID, номер/связь повтора, UTC,
роль/агент/эпизод, отдельный run UUID, доступный контекст конфигурации/карты и
digest входа/тела. Незавершённая резервация остаётся в лимите 240. Новый сетевой
повтор получает новый ticket; автоматических повторов провайдера нет.
Kernel lock, атомарная замена и fsync защищают JSON. Идентичные аннотации не
увеличивают ревизию. Блокировки бюджетом пишутся отдельно без сетевого обращения.

Ответ API, JSON, схема, контроллерная допустимость и применение имеют отдельные
поля. Для Local DETOUR выдача команды — pending_ack; физическое применение
подтверждает только CommandResult completed. Global будущая очередь остаётся
future_queue_not_confirmed до отдельного свидетельства.

Все полученные числовые поля usage сохраняются отдельно с SHA-256 в
`D:/MetaRescue-output/api-accounting/ai-budget/raw-usage/`. Вложенные cache/reasoning
не прибавляются к общим токенам повторно. Документированная вторая часть cache
может быть вычислена из input и первой части, с явной меткой метода.
Противоречия, пропуски и отсутствие usage дают null с причиной. Неполный или
отклонённый ответ не исключается из расходов. Ключи и заголовки не записываются.

## Версионированная стоимость

Снимок `deepseek-flash-usd-20261111` проверен 2026-11-11 по
[официальной таблице](https://api-docs.deepseek.com/quick_start/pricing/).
USD за миллион токенов: off-peak hit/miss/output = 0.003/0.15/0.6;
peak = 0.006/0.3/1.2. [Формат usage](https://api-docs.deepseek.com/api/create-chat-completion/)
задаёт input как hit+miss и описывает детализации completion.

Денежная арифметика — Decimal. Неизвестный cache даёт интервал. В будние UTC
01–04/06–10 без проверенного календаря китайских праздников сохраняется
неопределённость peak/off-peak. Для иной UTC-даты проверки тарифа оценка становится
неизвестной до нового проверенного снимка. `--ai-tariff` передаёт новую редакцию;
старые записи сохраняют свой снимок и оценку. Структура файла не подтверждает
истинность пользовательских ставок. Валюты не конвертируются и суммируются отдельно.

Расчётная стоимость отделена от actual_debit. Относимого к этим обращениям
биллинга сейчас нет; actual_debit=null. Расходы рабочего чата Codex не оцениваются.

## Экспорты

controller.main сохраняет cumulative и run JSON/CSV/TXT, попытки и группировки
по модели/роли/назначению/run/эпизоду. Есть n, p50/p95 nearest-rank, средние с базой
расчёта, unknown/incomplete и остаток квоты. Manifest экспорта проходит
incomplete→complete с хэшами. Ошибка экспорта делает архив failed и даёт exit1.
Названия вложенных папок controller не объединяют разные миссии: run ID — UUID.
MOCK/OFF не расходуют LIVE-квоту. Historical-replay экспортирует исходные tickets
отдельно, с new_api_attempts=0/new_api_cost=0.
