Цель goal активна. Принят план из текущего чата: восемь событий v0.3,
правдоподобное окружение, местная безопасность без A*/NSGA-II, точки интеграции.

- Исходное состояние сохранено в `artifacts/quarter-v3/baseline/`: Source,
  генераторы, Config, Scenario, RescueQuarter.umap, кадры v2 и хэши.
- Оригинальные модели, библиотека prepared/v2 и RescueDistrict сохраняются.
- Реализация и проверки ещё продолжаются; создание файлов не является приёмкой.

Порядок: геометрия/опора → окна/разрушения → события/эффекты → исполнители и
интерфейсы → проверки отдельных сценариев и трёх seed 480 с → кадры/видео/отчёт.

  окна, последствия/истечение, защита базы. Отчёт environment-unit-tests/.

  Свидетельства сохранены отдельно `first-static-failed/`.

  MaterialsV3/Instances, ставит used_with_instanced_static_meshes, сохраняет

  V2-материалы на диске не меняются ради HISM. Checker теперь использует
  collapse_piece, а не порядок в массиве.
