# Конкурсные возмущения в Core

Версия приватной ленты `metarescue.disturbances.v1` дополняет физические профили
v0.5.2 и v3. Её проверяют Python и Unreal. Каждый запуск сохраняет точную
конфигурацию. Публичная карта исключает ленту и будущие события. Объявленные
времена применяются на границах часов эпизода, события с длительностью имеют
отдельный конец. Перекрывающиеся деградации используют меньший коэффициент.

| Источник | Физическое или наблюдаемое изменение |
| --- | --- |
| `agent_failure` | Тяга и разведка отключаются, носитель останавливается и освобождает груз в текущей позе. Отказ становится публичным после доставки состояния. |
| `agent_degradation` | Меняются предел скорости и вероятность сенсора. Публичные начало и восстановление следуют за отчётами агента. |
| `infrastructure_failure` | Зарядка или ретрансляция выключается. Состояние и восстановление объявляются станцией управления. |
| `connectivity_loss` | Устройства временно исключаются из радиографа. Публичный таймаут выводится из отсутствия доставленных отчётов. |
| `mission_priority_change` | Приоритет изменяется в среде. Для уже известной цели новое значение доставляется с отметкой времени. |
| `operator_directive` | Действующее распоряжение hold проверяется по агенту, сроку и фазе работы. Контроллер передаёт команду на безопасной границе обслуживания. |
| `restricted_zone_appeared` | Реальный ограниченный объём останавливает вход. Исключения заданы по категории агента. На публичном снимке объём влияет на A*. |
| `resource_shortage` | Уменьшается доступный запас зарядной станции. Отдельно записывается снятый объём энергии. |
| `contradictory_information` | Сведения с меньшим доверием сохраняются в реестре конфликтов. Положение цели сохраняется до свежей проверки. Подтверждающий осмотр закрывает конфликт. |

`hazard_appeared`, `environment_change`, `target_detected`, `target_state_changed`
и `stale_information` возникают из измерения, доставки и смены состояния. Все
14 типов перечислены в capabilities. Журнал связывает факт с источником и
временем получения. Состояние наблюдателя хранит собственные времена и исходы.
