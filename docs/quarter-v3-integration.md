# RescueQuarter v3: исполнение и подключение контроллера

Это физический стенд Unreal, отдельный от пользовательского 2D-бенчмарка и
нормативного Core Protocol 1.0. A*, NSGA-II, поиск объезда и новый HTTP-сервер
в этой редакции не добавляются. `AGENTS.md` остаётся общим файлом инструкций.

## Координаты и геометрия

Внутри UE используются сантиметры, X/Y в горизонтальной плоскости и Z вверх.
В API с суффиксом `Meters` — метры: `UE_cm = API_m × 100`. MRWorld в сохранённой
карте имеет нулевые положение/поворот и единичный масштаб. Работающая область
включает базу и район: X −30..170 м, Y −20..170 м, Z −3..60 м; фон выходит за
эти пределы. Не применять масштаб к актору MRWorld.

`Saved/Telemetry/environment-truth.json` — **закрытая диагностическая истина**.
Он содержит seed, будущую ленту событий, консервативные объёмы зданий, границы
и исходную сетку высот/проходимости `initial_ground_grid`. Размер динамической
ячейки — 5 м; это пространственная адаптация к 3D-кварталу, а не сетка 10 м из
2D-сценария. Сетка не заменяет точную проверку коллизий и габаритов машины.
Глубокий исходный провал имеет настоящий разрыв дорожной коллизии.

## Управление

Запуск с `--external-control` отключает локальный демонстрационный диспетчер
и его заранее заданные полёты. Наземная техника ждёт на базе, дроны стоят на
площадках. Управление доступно как внутренние Blueprint/C++ методы MRWorld:

| Вызов | Смысл |
|---|---|
| `SubmitRouteMeters(AgentKey, CommandId, PointsMeters)` | Принять последовательность точек без переноса машины |
| `HoldAgent(AgentKey, CommandId)` | Затормозить; дрон удерживает текущую высоту |
| `QuerySurfaceMeters(PositionMeters)` | Стоимость движения, глубина, качество видимости, блокировка, ревизия |
| `PublicObservationJson()` | Позы/скорости/состояния своих агентов и только обнаруженные люди |

Ключи агентов: `ground_0`..`ground_3`, `aerial_0`..`aerial_2`. `CommandId`
непустой и уникальный для новой команды. Повтор принятой команды с тем же
телом подтверждается без перезапуска, включая повтор старой команды после
новой. То же имя с другим телом отклоняется. За сброс эпизода сохраняется до
128 команд на агента; после этого новые команды отклоняются. Маршрут содержит
1..4096 конечных точек; NaN, бесконечные значения и выход за защитные числовые
границы отклоняются. Это не проверка достижимости каждого сегмента.

`hold` не сбрасывает груз и назначение. Новая принятая команда снимает hold.
До нового маршрута техника сохраняет своё фактическое положение; изменения
в координатах применяются силами и моментом. Перестановка `ResetTestPose`
существует только в явно включённых испытательных fixture до начала замеров.

`stop_reason`: `external_hold`, `yield_to_vehicle`, `obstacle_on_route` или
`hazard_on_route`; пустая строка означает отсутствие текущего запрета движения.
Уступание временное и отдельно от `route_blocked`. Постоянная блокировка
публикуется после остановки более четырёх секунд; исчезновение препятствия
разрешает продолжение заданного маршрута. Автоматический объезд отсутствует.
`stop_obstacle` в диагностической телеметрии называет реальный коллайдер.

Состояние агента включает команду, позу, скорость, расход энергии по реально
пройденному расстоянию и `carrying`. Завершение внешнего маршрута не выгружает
груз автоматически. Наземная масса 240 кг, с пациентом 320 кг. Посадочная
команда дрону заканчивается возле его собственной площадки на её высоте.

## Истина и наблюдение

`public-observation.json` не содержит будущих событий и скрытых людей.
Новый пострадавший становится доступен физическому обнаружению после события;
публичная цель появляется только после наблюдения и получения сообщения.
Файл `environment-truth.json`, полные `events.jsonl` и `frames.jsonl` служат
исследованию/приёмке; не подавать их в будущий контроллер как наблюдения.

`QuerySurfaceMeters` — диагностическое чтение истины среды для построения
адаптера. В нормативном подключении фильтрацию доступных сведений должен
реализовать адаптер среды, а не алгоритм контроллера.

## Настройка событий

Единый блок значений — `MRDistrictSettings.h`. По всему району на каждое окно
30 модельных секунд назначается одна попытка каждого из восьми типов:
12/12/10/14/14/15/12/20%. При горизонте 480 с основные окна — 30..450 с.
Для огня и воды возможны ещё два следующих окна распространения, .72/.65.
FRandomStream отделён от движения, Chaos и эффектов; одинаковый seed даёт
одинаковую ленту. Совпадение битов с Python MT19937 v0.3 не заявляется.

```powershell
python -B -X utf8 unreal/launch.py --quarter --editor --environment random --seed 20261109
python -B -X utf8 unreal/launch.py --quarter --editor --environment static
python -B -X utf8 unreal/launch.py --quarter --editor --environment showcase
```

`--probability fire=0` меняет отдельную вероятность без пересборки. При восьми
нулях нет случайных и вторичных событий. `static` вообще не создаёт ленты.
`showcase` — явно постановочный показ восьми эффектов, не случайный эксперимент.
Защищённая база не зависит от положения роботов. Исчерпание подходящих мест
и неприменимые попытки записываются как `environment_attempt_rejected`.

Дым .52 действует 90 с, дым от пожара — 70 с, завеса .62 — 100 с; дым и завеса
перемножаются. Грязь даёт стоимость 2.25, повреждённая дорога — 1.90, мелкая
вода — 2.0. Вода растёт до 42 см со скоростью .8 см/с; глубже 25 см проезд
запрещён. В 3D уровень воды согласован с полуметровыми замерами основания,
обрезан у зданий и не создаётся на крышах. Это ограниченное поле, без полной
гидродинамики, плавучести, тушения или расчистки.

Эффекты Niagara используют ограниченные bounds и дальность отображения;
отключение картинки не убирает опасность из среды. Материалы стекла используют
Thin Translucent и Surface ForwardShading; Opacity означает загрязняющий слой,
а пропускание задаётся отдельным Thin Translucent Output. Основа —
[документация Epic по прозрачности](https://dev.epicgames.com/documentation/unreal-engine/lit-translucency-in-unreal-engine?application_version=5.8)
и [рекомендации Niagara](https://dev.epicgames.com/documentation/unreal-engine/scalability-and-best-practices-for-niagara?application_version=5.8).

## Воспроизведение приёмки

`run_quarter_validation.py` последовательно запускает native UE и сохраняет
свежие кадры, команду, логи, телеметрию и результат проверки в уникальную
папку `artifacts/quarter-v3/runs/<prefix>-...`. Одновременные Unreal-прогоны
запрещены: они используют общий Saved. Сборку и пересоздание карты выполнять
при закрытом пользовательском редакторе, сохранив его правки.

```powershell
python -B -X utf8 unreal/tools/run_quarter_validation.py static --prefix my-run
python -B -X utf8 unreal/tools/run_quarter_validation.py traffic --prefix my-run
python -B -X utf8 unreal/tools/run_quarter_validation.py effects --prefix my-run
python -B -X utf8 unreal/tools/run_quarter_validation.py random --prefix my-run
python -B -X utf8 unreal/tools/run_quarter_validation.py showcase --prefix my-run
```

Наличие команды здесь не означает её успешное выполнение. Итоговые результаты
и проверенные ограничения должны читаться из отчёта приёмки и свежих архивов.
