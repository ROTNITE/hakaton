# Проверка Rescue Lab

План UI-проверки (до начала браузерного прогона):

| Возможность | Функциональная проверка | Визуальное состояние |
|---|---|---|
| Две страницы и четыре алгоритма | Переключить разведку/эвакуацию, проверить подписи и сброс времени | Обе страницы, 4 поля |
| Шаг, запуск, пауза, темп, повтор | Шаг увеличивает время на 1; запуск двигает; пауза останавливает; повтор обнуляет | Начало и движение |
| Настройки | Изменить карту, людей, дронов, роботов, энергию, seed, NSGA и общую разведку; применить | Новая карта и подписи |
| Скрытые люди и пути | Переключить оба флажка | Режим наблюдателя и маршруты |
| Метрики и баллы | Довести эпизод до завершения; проверить время, энергию, count и ранжирование | Финальный рейтинг и широкая таблица |
| Читаемые графики | Проверить отдельный график под каждой картой и одинаковые шкалы | Заполненные графики |
| NSGA-II | Открыть поколения, подвигать ползунок, закрыть | Фронт и три значения целей |
| Серия | Запустить 3+ seed, дождаться результата; отменить отдельную серию | Прогресс и таблица μ ± σ |
| Экспорт | Скачать CSV/JSON текущего опыта и серии; проверить содержимое | Кнопки и доступность |
| Адаптивность | Desktop 1440×1000 и mobile 390×844; весь документ без горизонтального переполнения | Скриншоты обоих размеров |
| Нестандартный сценарий 1 | Пауза/сброс во время выполнения; исключить устаревшие шаги | Чистое состояние после сброса |
| Нестандартный сценарий 2 | Недопустимые настройки и отмена длинной серии; UI остаётся рабочим | Ошибка валидации / отменённая серия |

Дополнительно: unittest для NSGA, физики 2D-перемещения, энергии, дедлайнов, видимости, детерминизма, HTTP и серии; запуск из распакованного ZIP с пробелами и кириллицей в пути.

Выполнено 2026-11-09:
- 19 unittest бенчмарка проходят; 15 исходных проверок контракта проекта проходят.
- JavaScript: `node --check` проходит.
- Playwright Chromium: обе страницы, шаг/запуск/пауза/сброс, смена всех числовых настроек и общей разведки, наблюдатель, пути, завершённый эпизод, поколения, CSV опыта, JSON серии, серия из 3 карт и отмена серии из 20 карт проверены обычными действиями в UI. CSV серии и JSON опыта используют те же обработчики выгрузки; HTTP JSON экспорта дополнительно покрыт тестом.
- Невалидная ширина 0 отклоняется браузером; сброс во время воспроизведения возвращает сценарий в 0 без последующих старых шагов.
- Отдельная визуальная проверка desktop 1440×1000 и mobile 390×844: четыре поля, отдельные графики, итоговая таблица; горизонтального переполнения документа нет. Широкая таблица прокручивается внутри контейнера. Ошибок JavaScript/console не обнаружено.
- Масштабный smoke: 120×120, 120 людей, 12 дронов, 16 роботов, 30 модельных шагов выполнены за 0.161 с на текущем ПК (популяция 24, поколения 8). Это проверка запуска, не оценка полного максимального сценария.
- Измерены две серии по 5 карт seed 42–46; исходные CSV/JSON включены в архив.

Скриншоты и проверка распакованного архива хранятся в `artifacts/benchmark/` основного репозитория. Не проверялись реальные роботы, другие ОС, полная максимальная конфигурация 64×24 поиска, а также 3D в рамках данного стенда.
