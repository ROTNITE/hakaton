# Деревья и древесные обломки для MetaRescue

Подборка от 11 ноября 2026 для реалистичного городского квартала после
землетрясения: 12 исходных наборов Poly Haven. Каждый скачивается в оригинальных
форматах **Blender и FBX**, вместе со всеми объявленными зависимостями и
PBR-текстурами **2K**. Файлы находятся в `polyhaven/<идентификатор>/`.
Один набор может содержать несколько деревьев, вспомогательные ветки и LOD.

Начать просмотр: [локальная галерея](index.html). В ней есть превью автора,
назначение и ссылки на локальные модели. Это исходники для подготовки, а не
скриншоты нашей сцены и не уже импортированные Unreal-ассеты.

## Художественный отбор и ограничения

Приоритет для детального квартала: Tree Small 02 + оба Dead Tree Trunk +
Dry Branches + оба Tree Stump. Хвойные подходят для сквера и зелёной периферии;
плотный лес перекроет читаемость улиц, пострадавших и маршрутов роботов.
Тропические, пустынные и ярко мультяшные деревья не включены в подборку.

Это природные, местами старые и мшистые обломки. Для свежего повреждения после
землетрясения понадобятся светлая древесина на изломе, уменьшение мха,
строительная пыль и согласованная пара «пень + упавшая верхушка». Такая доработка
ещё не выполнена. Наборы не образуют готовую систему физического разрушения.

Взрослые деревья очень плотные. Показатель `source_polycount` в API-каталоге
не является бюджетом одного игрового экземпляра. Blender-аудит отдельно считает
геометрию **до модификаторов**, включая вспомогательные объекты и LOD; суммы
по набору нельзя выдавать за сложность одной видимой кроны.

Перед использованием в UE нужно выбрать конкретные варианты и LOD, проверить
масштаб/ось/pivot, настроить листву (alpha/masked, двустороннее освещение),
материалы, нормали и простую коллизию стволов. Файлы `nor_gl` имеют OpenGL-
направление нормали: при использовании в UE проверить зелёный канал.
Ссылки на `textures/` относительные — переносить всю папку набора целиком.
Geometry Nodes, если они есть в исходнике, требуют отдельной подготовки к экспорту.
Импорт, коллизии, освещение и производительность в UE этой загрузкой не проверены.

## Источники и лицензия

Сохранены `CC0-1.0.txt`, снимок страницы `polyhaven-license.html`, исходные

У оригинального Dry Branches обнаружена оставшаяся абсолютная ссылка
`D:\Polyhaven\Local\polyhaven asset library\abandoned_hopper_terminal_02\abandoned_hopper_terminal_02_1k.hdr`.
Это фон освещения автора, а не текстура веток. Оригинал сохранён без изменений.
В `extras/` дополнительно скачан этот HDRI 1K с официального Poly Haven;
его источник, авторы и хэши находятся в `catalog.json`, раздел `supplements`.
Генератор `prepare_branches_copy.py` создал отдельный
`prepared/dry_branches_medium_01_2k.blend`: фон подключён, все четыре изображения
упакованы внутрь, геометрия и материалы не менялись. Галерея ссылается на эту
переносимую копию; FBX набора не зависит от World-фона Blender.

## Получение и проверка

Из корня проекта, Python 3.10+ и стандартная библиотека:

```powershell
python -B -X utf8 blender/vegetation/download_assets.py
python -B -X utf8 blender/vegetation/download_assets.py --verify-only
python -B -X utf8 blender/vegetation/build_gallery.py
```

Загрузчик использует сохранённые снимки API, проверяет размер и MD5 каждого
файла, вычисляет SHA-256. Уже существующий изменённый файл сохраняется и вызывает
ошибку. `--verify-only` работает локально, ничего не скачивает и не меняет каталог.
Новые внешние зависимости не добавлены.

Пример открытия дерева:

```powershell
python -B -X utf8 blender/launch.py blender/vegetation/polyhaven/tree_small_02/tree_small_02_2k.blend
```

Пример чтения исходника без сохранения и выполнения вложенных скриптов:

```powershell
& '.tools/blender/blender-4.5.15-windows-x64/blender.exe' --background --factory-startup --disable-autoexec --python-exit-code 1 --python blender/vegetation/audit_blender.py -- blender/vegetation/polyhaven/tree_small_02/tree_small_02_2k.blend D:/MetaRescue-output/vegetation-2026-11-11/blender-audits/tree_small_02.json
```

Аудит проверяет открытие, наличие сеток, доступность и размеры текстур, UV,
модификаторы, единицы и неизменность SHA-256 исходного `.blend`.
Отчёты конкретного выполнения и логи находятся на
`D:/MetaRescue-output/vegetation-2026-11-11/`.

Воспроизведение исправленной копии веток (останавливается, если копия уже есть):

```powershell
& '.tools/blender/blender-4.5.15-windows-x64/blender.exe' --background --factory-startup --disable-autoexec --python-exit-code 1 --python blender/vegetation/prepare_branches_copy.py
```
