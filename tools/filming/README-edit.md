# Повторяемый монтаж MetaEvolution Rescue

Локальный монтаж нативных кадров Unreal. Исходники проекта и кадры не меняются.
Новых зависимостей не добавлено: используются установленные Python, Pillow,
NumPy, FFmpeg и FFprobe. Каждый запуск требует новый каталог результата.

```powershell
python -B -X utf8 compose_film.py edit.json D:/MetaRescue-output/filming/edit-01
python -B -X utf8 compose_film.py edit.json D:/MetaRescue-output/filming/edit-01 --validate-only
python -B -X utf8 -m unittest discover -s . -p test_compose_film.py -v
```

Пример спецификации:

```json
{
  "fps": 30,
  "shots": [
    {
      "id": "01-city",
      "frames": "D:/MetaRescue-output/filming/native/01-city",
      "start": 0,
      "end": 8,
      "kicker": "01 / ПОСЛЕ КАТАСТРОФЫ",
      "title": "Город ждёт помощи",
      "subtitle": "Реальная сцена проекта в Unreal Engine",
      "provenance": "ПОСТАНОВОЧНАЯ ДЕМОНСТРАЦИЯ В UNREAL ENGINE",
      "title_seconds": 5
    }
  ],
  "credit": "Точный перечень реальных механик и постановочных элементов хранится рядом с фильмом."
}
```

В каждой папке кадры `frame-000000.png`, `frame-000001.png` и далее без пропусков.
`start` и `end` задаются в секундах исходной последовательности; `end` можно
опустить. Границы округляются до ближайшего кадра. В JSON относительные пути
считаются от файла спецификации. Текст можно опустить. `title_seconds` ограничивает
показ нижнего титра. Источник произвольного размера масштабируется с центральной
обрезкой до 1920×1080; важные детали нужно держать в безопасной зоне 16:9.
Нижний титр плавно появляется и исчезает за 0,25 с; на коротких планах
интервал автоматически сокращается. `title_seconds: 0` отключает нижний титр.
Значение длительностью не более одного кадра также не выводит титр.

Результат `film.mp4` использует H.264, yuv420p, AAC stereo 48 kHz и faststart.
Сохраняются промежуточные клипы, PNG титров, WAV, точная JSON-спецификация,
копия скрипта, SHA-256 первого/последнего исходного кадра каждого плана,
метаданные FFprobe и журнал полной проверки декодирования изображения и звука.

Монтаж добавляет умеренную холодную цветокоррекцию с тёплыми светами,
лёгкую виньетку, узкие кинематографические поля, титры и затемнение на склейках.
Титры и музыка являются художественным оформлением и не доказывают механику.
Музыка синтезируется этим скриптом с нуля, без сторонних сэмплов и композиций.
Лицензии исходных 3D-ассетов остаются в каталоге происхождения основного проекта.

Автопроверка подтверждает декодирование, формат, размер, точную сумму кадров,
длительность и наличие аудиодорожки. Художественную читаемость изображения и
качество прослушивания следует дополнительно проверить при просмотре фильма.
